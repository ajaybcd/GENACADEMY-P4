Clarified refund-processing instruction

Refund-processing exceptions: If the customer has already returned an item and is waiting for refund money, choose refund_request. A missing, delayed, or not-yet-received refund payment on a card is a refund-processing issue, not a missing delivery. If the customer asks to cancel an unwanted order and receive a refund because they no longer need it, choose refund_request unless an actual non-delivery or delivered-product problem is stated. Mentioning an order number, waiting, a card, or a refund does not by itself establish an order_status issue. Apply the underlying-problem precedence above only when the query actually describes an order that was not delivered or a delivered item that is damaged, wrong, defective, or not as described.
